# Working on this repo

This repo ships skills, hooks and scripts for Claude Code and OpenCode. It is
not an application.

## Layout

- `skills/<name>/SKILL.md`: one directory per skill, flat. Detail goes in
  sibling files one level deep. Skills link to each other only within
  `skills/` (`../do-it/STATE.md`), so links survive a symlink install.
- `agents/`: role agents (scout, reviewer, builder, planner, skeptic), each
  pinning its model and tools; skills name them instead of describing a tier.
  The voice block in each is copied from `skills/it-core/VOICE.md` by
  `npm run gen`; edit the source, not the copies.
- `hooks/`: `claude.mjs` (Claude Code entry), `lib/` (host-neutral checks
  and context), `hooks.json` (plugin hook config).
- `.opencode/plugins/`: the OpenCode plugin, a thin adapter over `hooks/lib`.
- `.opencode/command/`: generated by `npm run gen`. Never edit by hand.
- `scripts/`: install, generate, check.
- `docs/DESIGN.md`, `docs/adr/`: why things are the way they are.

## Rules

How to write a skill (typed vs automatic, descriptions, calling other
skills, file layout, line budget, `-it` names) is in
[skills/skill-it/SKILL-MECHANICS.md](skills/skill-it/SKILL-MECHANICS.md);
`npm run check` enforces it. This repo adds:

- `skills/it-core/SKILL.md` is the single source of the coding posture; the
  hooks and the OpenCode plugin read it. Do not restate it elsewhere.
- Check a new skill name against mattpocock/skills and rshingleton/skills.
- A new model-invoked skill needs positive and negative prompts in
  `evals/routing.json`; `npm run check` runs the routing eval.
- Skills are written in this repo's own words. Ideas from other repos are
  welcome and credited in the README; their text is not copied in.
- No em-dashes in skills.
- No runtime dependencies. Node 18+ built-ins and bash only.
- Hooks fail open: a crash or bad input must never block the agent.
- No AI attribution in commits, docs or code comments.

## Before handing off

```bash
npm test && npm run check
```

Add an ADR in `docs/adr/` for a decision that is hard to reverse, surprising
without context, and the result of a real trade-off.
